# Android UI 统一优化记录（2026-11-05）

基线：`dev`（`074667c` 之后）。只调整视觉与布局，不改业务逻辑、接口与导航。

## 一、本轮改动

### 评论区（`activity_detail.xml` + `item_comment.xml` + `CommentAdapter` 既有逻辑）

- 一级评论与二级回复的层级：一级左缩进 16dp、头像 32dp；二级左缩进 52dp、头像 24dp
- 「回复 @某人：」前缀使用 `profile_muted` 弱化色，正文保持 `profile_ink`
- 「自动回复」徽标改为 `profile_badge` + `profile_accent` 文字，不再像报错标签
- 时间与「回复」同一行：时间居左、回复右对齐，点击热区 40dp

### 自动回复（`activity_auto_reply.xml`、`item_auto_reply.xml`、`activity_auto_reply_edit.xml`）

- 规则列表卡片化（`bg_rule_card`）：场景标题 + 答案正文 + 开关 + 删除
- 编辑页 AI 提炼区与手动填写区用 `divider_horizontal` 分区，候选行使用统一复选框样式

### 长文提炼弹窗

- 从代码里手搭的 `AlertDialog` 改为 `dialog_post_summary.xml`：正文可滚动、底部固定免责说明，加载态与结果态共用同一布局

### 消息页（`fragment_messages.xml` + `MessagesFragment`）

- 顶栏 56dp，标题 20sp `profile_ink`；「全部已读」热区 40dp
- `@我 / 回复 / 赞` 改为分段控件：浅紫底槽 `bg_segment_container` + 白色药丸选中态 `bg_segment_selected`，选中加粗
- 空态与游客态改为「图标 + 文案」居中块（`messages_empty_group` / `messages_login_group`）
- 设置入口从系统 `ic_menu_preferences` 换成自绘 `ic_settings`

### 通知条目（`item_notification.xml`）

- 头像 44dp、正文 14sp `profile_ink`、时间 12sp `profile_muted`
- 未读圆点与消息 Tab 角标同色；条目之间加 `divider_horizontal` 分割

### 令牌清理

- `dialog_notification_settings`、`item_loading_more`、`fragment_friends` 中残留的 `#8A8A8E / #1A1A1A / #666666 / #FFFFFF` 全部替换为 `profile_*` 令牌
- 新增 drawable：`bg_segment_container`、`bg_segment_selected`、`ic_settings`、`divider_horizontal`、`bg_rule_card`；新增 `color/button_accent_tint`
