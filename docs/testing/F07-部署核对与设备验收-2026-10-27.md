设备为 Pixel_2_API_36 / Android 16。应用使用真实 `ApiClient`、Keystore 和系统 DocumentsUI；本机 Python HTTP fixture 始终在 App 进程外运行，App 被停止后服务仍在，因此能够验证跨进程恢复。

重新准备独立包（在主仓库目录执行，目标工作树需尚不存在）：

```powershell
$deviceTree = Join-Path (Split-Path (Get-Location).Path -Parent) 'f07-device-validation'
git worktree add --detach $deviceTree HEAD
Copy-Item -Path 'app/src/*' -Destination (Join-Path $deviceTree 'app/src') -Recurse -Force
Copy-Item -LiteralPath 'app/build.gradle.kts' -Destination (Join-Path $deviceTree 'app/build.gradle.kts') -Force
Copy-Item -LiteralPath 'local.properties' -Destination (Join-Path $deviceTree 'local.properties') -Force
$buildFile = Join-Path $deviceTree 'app/build.gradle.kts'
[IO.File]::WriteAllText($buildFile, [IO.File]::ReadAllText($buildFile).Replace('applicationId = "com.PixelFlow.app"', 'applicationId = "com.PixelFlow.app.acceptance"'))
[IO.File]::WriteAllText((Join-Path $deviceTree 'app/src/main/assets/api.properties'), "url=http://127.0.0.1:18765`n")
$env:JAVA_HOME = 'D:\Android Studio\jbr'
Push-Location $deviceTree
./gradlew.bat :app:assembleDebug --console=plain
Pop-Location
python tools/android/device_acceptance.py --adb 'C:\Users\HP\AppData\Local\Android\Sdk\platform-tools\adb.exe' --apk (Join-Path $deviceTree 'app/build/outputs/apk/debug/app-debug.apk') --out 'build/f07-device-evidence'
```

适用当前 Windows SDK、API 36 英文系统选图器。脚本不修改正常 App 数据，不访问云端；测试图片留在专用模拟器 Downloads 中。实际 Java 服务语义仍由后端专项验收负责。
