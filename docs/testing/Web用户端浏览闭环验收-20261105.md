# Web 用户端浏览闭环验收

- 日期：2026-11-05；分支：feature/us-09-web-user-2；基线：900e69b。被测内容为本分支未提交工作区。
- 环境：Windows、Java 17.0.12、现有基线 JAR、隔离 H2 内存库 `web_user_test`（MySQL 模式），Vue 3 + Vite；Kimi Desktop 内置浏览器，截图视口 808×893。
- Java 仅监听 127.0.0.1:8080；Vite 使用 5173，重启后使用 5174。没有访问共享/云端数据库，没有改 Java、Android、Python 或契约。

## 实际验证

| 场景 | 结果 |
| --- | --- |
| 游客首页与详情 | 可展示公开作品；详情关注按钮可点击并跳登录 |
| 游客搜索 | 搜索“猫”展示公开卡片；无结果显示专用空态 |
| 未登录访问 /me | 跳 /login?from=/me；注册成功回个人中心 |
| 详情关注 | 点击成功，刷新后仍为“已关注” |
| 详情取关 | 点击成功，刷新后为“关注” |
| 本人作品 | 通过详情登录引导登录作者，回原详情，无关注按钮 |
| 个人中心 | 当前用户昵称和字母头像兜底、收藏和关注入口可见 |
| 收藏分页 | HTTP 准备 25 条收藏，首屏20条，加载更多到末页，不再提供加载按钮 |
| 搜索分页 | 25 篇唯一编号作品，加载后页面包含25到01，各一次 |
| 作者作品分页 | 25 篇作品，页面链接快照确认25条，各编号一次 |
| 关注名单分页 | 22人，首屏20人，加载更多后22人 |
| 作者页 | 昵称、真实头像、空简介兜底及作品展示正常 |
| 请求失败 | 停止本次后端后，搜索和收藏均展示错误及重试按钮，未误报空列表 |
| 服务恢复 | 重启隔离服务后，游客搜索重新可用；未将服务重启导致的失效会话当作正常登录 |
| 构建 | npm ci && npm run build 通过；依赖安装曾自动重试损坏缓存，最终成功，审计0漏洞 |

关注初始状态来自既有 GET /api/users/{id}/profile 的 is_following，不遍历关注列表。该接口及作者作品均要求登录，因此游客进入作者页先登录回跳，不扩展服务端权限。/me/following 只读，不新增粉丝或关系管理。

## 数据与复现

本次使用 PIXELFLOW_SEED=true 的随包演示素材，另通过 HTTP 注册作者、访问者和21名关注对象，创建并提交25篇作品，由本次临时管理员通过现有审核接口批准，访问者收藏25篇并关注22人。未直接写数据库状态。准备脚本与临时凭据仅存在被忽略的 server/target，未纳入交付。

按 web-app/README.md 启动现有 Java 服务与 Vite，使用自己的本地测试账号复现：详情关注/刷新/取关；搜索关键词并加载更多；个人中心进入收藏与关注；点击卡片作者进入主页。临时内存服务结束后数据消失。

## 补充验收（2026-11-05）

被测前端提交：26f7202（包含此前两次功能提交）。本轮 Java 使用 8081，Vite 固定为 5175；8080 为仅本机测试代理，正常业务转发到真实 Java。代理及故障开关均在忽略的 server/target 下，不属于产品交付，不修改后端或契约。

| 补验项 | 操作及实际结果 |
| --- | --- |
| 首屏错误重试 | 仅对搜索注入 HTTP 503，出现错误和重试按钮；关闭故障后在同一页面点击“重试”，恢复20条首屏作品，未刷新页面 |
| 续页错误重试 | 仅对带 cursor 的搜索请求注入503，点击“加载更多”后原20条保留；关闭故障，点击“重试”，得到25条作品，编号25到01各一次，无遗漏，未重新加载首屏 |
| 首页作者入口 | 游客点击首页卡片作者，进入带作者地址 from 的登录页；登录后回到该作者主页，展示正确昵称及作品 |
| 详情作者入口 | 登录后从作品72点击“验收作者”，进入同一作者主页 |
| 个人中心头像展示 | 测试代理仅在成功的 /api/users/me 响应中填入随包演示头像URL，/me 实际加载该图片并显示，见下方截图；字母头像兜底已在前轮实测 |

[个人中心头像响应夹具截图](web-user/me-avatar-fixture.png)

头像测试边界：当前 Java 源码未实现契约中的 PUT /api/users/me/avatar，本轮调用返回404。因此头像项只证明 Web 能展示既有资料字段中的有效图片URL，不能称为真实账号头像设置链路通过。本 issue 仅要求只读展示，不为此扩展后端；需在 PR 说明这一现有接口缺口。其余补验的搜索、作品、作者及认证响应均来自隔离 Java 服务，503为受控故障注入。
