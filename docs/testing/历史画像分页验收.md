## 审查补丁

- 转换分页参数前先去掉前导零并检查有效数字长度，避免超长数字触发 Python 整数转换异常；非法值仍返回 422 和 no-store。
- 对查询得到的 count+1 条全部校验，再截取本页；额外一条损坏时返回脱敏 503，更远的损坏记录不影响本页。

- 补充超长 count/cursor、前导零、topics/media 超大分数、损坏预读行及读取范围之外记录的回归测试，并同步 HTTP 契约。
