# UI 页面状态保留修复（2026-11-10）

## 行为变化

- 底部导航按 Fragment 标签复用实例，通过显示/隐藏切换，隐藏页限制在 STARTED；保留列表与滚动状态。回到首页恢复沉浸式系统栏。
- AccountDataActivity 已加载成功且账号未变时，返回保留内容和操作令牌；未完成读取或写入需要核对时重读，账号变化时清理旧内容。我的作品、收藏因详情可能修改数据，继续返回刷新。
- 消息三分类各自保留数据、游标、hasMore 和滚动状态；已加载分类切回不重读，首次加载显示刷新指示器。全部已读/屏蔽变更使分类缓存失效；旧分类、旧账号、已销毁视图的响应不可回写。
- 兴趣画像加载成功后普通返回不重建；中断或失败允许重试，账号变化重新读取。
- 搜索通过 Activity ViewModel 保留已加载结果、游标、滚动状态及 AI 收起状态；旋转恢复不重新请求已完成的普通检索，不自动弹键盘。进程被系统杀死后只恢复查询并重新读取，不把整个列表写入 Bundle。
- 编辑资料返回携带服务器确认的昵称、简介与会话标识；个人页先同步缓存，忽略其他账号结果并取消旧请求，后台刷新失败仍保留已保存内容。单纯底部切换不重复刷新个人页。
