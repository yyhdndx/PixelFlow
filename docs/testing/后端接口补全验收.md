# 后端接口补全验收

日期：2026-10-21。开发基线 master `6e9f05e`，开发分支 `feature/backend-api-completion`。本轮交付任务03及Java历史画像代理（任务10）；代码交付与线上部署分别验收，线上可用性以实际发布版本为准。

## 交付范围

| 接口 | 参数 | 响应与边界 |
| --- | --- | --- |
| GET `/api/users/me/favorites` | count、cursor | 完整收藏卡片、当前用户点赞状态、is_favorited=true；数字has_more；只返回启用作者的公开作品，按作品数字ID降序 |
| GET `/api/users/me/profile/history` | count、before_version | 本人历史摘要，按版本数字降序；布尔has_more；不按当前推荐偏好改写，不触发同步/重算 |

两者均需要当前用户Bearer身份，count默认20、范围1–50，游标首次省略、值范围1–9223372036854775807。只接受ASCII十进制正整数，允许前导零；空值、重复分页参数、非数字和越界返回400 `INVALID_ARGUMENT`。下一页传返回的next_cursor，末页为null。查询参数不能切换身份，成功及业务错误均禁止缓存。

不新增数据库结构、依赖或配置项。原有Feed、详情、收藏ID列表/写入、当前画像语义保持不变。作者作品分页07继续由Java同学完成；头像09保留 `feature/user-avatar`，未纳入本分支。推荐交付、Agent/MCP、Android页面和服务器发布不在本轮。

## 调用示例

以下为本地联调路径，令牌使用自己测试账号的access token。作品ID/画像版本是示例，不是云端数据。

```http
GET /api/users/me/favorites?count=1
Authorization: Bearer <access-token>

GET /api/users/me/favorites?count=1&cursor=10
Authorization: Bearer <access-token>

GET /api/users/me/profile/history?count=1
Authorization: Bearer <access-token>

GET /api/users/me/profile/history?count=1&before_version=8
Authorization: Bearer <access-token>
```

收藏夹具有公开作品10、9时，第一页post_list含10，has_more=1、next_cursor="10"；下一页含9，has_more=0、next_cursor=null。撤回10后刷新第一页仅剩9。取消收藏不改变作品ID排序，再次收藏也不会按收藏时间置顶。count+1读取前已完成归属及可见性过滤；非法target_id如09、9x或9.0不会被MySQL隐式转换误匹配。

历史快照版本8、5时，count=1第一页items含version=8，has_more=true、next_cursor="8"；下一页含5，has_more=false、next_cursor=null。无历史返回空items。Java只透传本次Bearer和校验后的分页参数，不传客户端给出的user_id；响应身份不符或摘要/分页无效为502，分析端不可用为503，上游401映射401，均不回显上游正文。
