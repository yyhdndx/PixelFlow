# DeepSeek 创作辅助（2026-10-31）

开发分支：`feature/deepseek-creation-assist`。原工作区已先推送 master，随后开发此功能；本功能未合并 master、未部署线上。

## 实现

- Python 服务端固定调用 `https://api.deepseek.com/chat/completions`，使用 `deepseek-flash`、JSON 输出和非思考模式。用户 ID、会话 token 不发给模型；只发送文字快照、主题、目标读者和生成目标。
- 模型返回按字段类型、长度、候选数量校验。拒绝空结果、截断结果、额外字段和非法话题；上游错误统一返回可重试的 503，不暴露原始错误或凭据。
- 原稿及生成候选均经过 content_safety，保留最高风险。检查属于规则提示，不自动发布、处罚或替代人工审核。
- 每进程最多两个并发模型请求；繁忙直接失败；Python 请求预算 35 秒/上下文 40 秒、Java 45 秒、Android 55 秒。模型失败不会悄悄换成模板；未配置模型密钥时显式标记 provider=rules。
- Android 提供综合优化、标题、正文润色、按主题写文案、话题五种目标和目标读者输入。候选默认保留原文，用户选择后才填入本地草稿；继续使用原保存/提交审核流程。
- 支持取消、重试、跳过；Activity 重建保留内存中的请求/预览；进程死亡后原稿仍按既有恢复机制保存，候选需要重新生成。编辑期间改变原稿会拒绝迟到建议，确认前再次检查快照。账号变化或页面销毁后不会应用旧回调。
- 话题选择明确显示“将话题加入正文”。当前没有独立话题持久化字段，不伪装成独立标签关联功能。
- Java 生成建议时用自身 UUID 替换上游 ID，并保存用户归属、文字快照、候选和 24 小时有效期。V11 新增 `creation_suggestions`；采纳时检查归属、有效期、候选成员、原稿匹配、版本和作品状态。
- 服务端采纳接口对同一建议、相同作品/版本/选择返回第一次响应，不重复写入；改变选择返回 409。此接口用于已保存草稿的直接采纳，Android 当前采用本地编辑器路径。
- 补全 OpenAPI 契约。管理员安全检查接口、独立话题表和通用自主 Agent 规划不包含在此次功能中。

## 密钥与运行

- 密钥只通过 Python 服务端环境变量 `DEEPSEEK_API_KEY` 读取；模型名通过 `DEEPSEEK_MODEL` 配置。仓库 `.env.example` 仅含空占位。
- 本次真实验证所用配置位于本地 `intelligence/.env.deepseek`，已确认被 Git 忽略；程序不会自动加载它，启动服务时需要由进程环境或服务管理器加载。不得将此文件打入 APK、构建产物或 Git。
- 部署时将变量放入服务器受限的环境文件，由 Python 服务读取。Java 的 intelligence-base-url 指向 Python 服务即可；Android 只访问 Java。
- 生产数据库 V10/V11 迁移需沿用现有备份与迁移审核流程，本轮不执行部署。
- 真实 API 已成功验证：模型目录返回 `deepseek-flash` / `deepseek-v4-pro`；以普通咖啡主题执行一次综合建议生成，约 2.06 秒，候选字段校验通过。该请求不使用用户真实草稿。
- DeepSeek 接口依据：[官方 JSON Output 文档](https://api-docs.deepseek.com/guides/json_mode/)。
