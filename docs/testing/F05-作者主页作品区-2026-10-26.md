# F05 作者主页作品区

日期：2026-10-26。范围：本地 Android 前端，在保留 F01–F04 未提交改动的基础上继续开发。
本地基线为 `07bf56a`；远程 master 的任务 11 已合入，但本轮没有合并远程 Java 改动、推送或部署。

## 实现

- 作者主页保留头像、简介、统计和关注操作，将作品占位区替换为双列卡片；展示封面、图文/视频标识、
  标题和当前访问者点赞状态，顶部提供刷新。
- `CommunityClient.getUserPosts` 调用现有认证接口 `GET /api/users/{id}/posts?count=20&cursor=...`；
  使用独立 `UserPostsPage` 解析包装对象，不与本人作品数组接口混用，不要求尚未部署的收藏字段。
- 验证作者归属、PUBLISHED 状态、严格降序 ID、页大小、数字 has_more 与下一页游标；异常响应不会
  当作空作品或追加重复条目。保留服务端 HTTP 状态供页面区分作者不可见和临时失败。
- 加载更多失败保留已加载卡片和原游标，重试只请求失败页；第一页成功为空、末页、失败分别呈现。
- 进入后台清空页面并取消读取；恢复、重建和详情返回从首页重新核对。账号变化时丢弃旧回调，避免
  将上一访问者的点赞/关注状态带到新会话。404/认证不可用清除旧头部和作品，不继续展示缓存条目。
- 卡片打开现有作品详情，复用其点赞、收藏和返回流程。图片使用现有 `AccountMedia`，账号图片不进入
  Glide 磁盘/内存缓存，不向外站图片附加认证；列表移除时清理图片请求。

## 复跑

使用 JDK 17 和 Android SDK，先启动模拟器，再在仓库根目录执行：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:connectedDebugAndroidTest :app:lintDebug --console=plain
```

新增 JVM 测试为 `UserPostsClientTest`：认证分页、访问者点赞、空页、Long.MAX_VALUE ID、
错误作者/私有作品/畸形响应、重复和越界游标、无效参数、401 刷新、404 及游客身份。

新增设备测试为 `UserPostsFlowTest`：翻页重试、空页与错误区别、作者停用、退后台、页面重建、
账号切换、打开详情与返回刷新，以及可供视觉检查的示例页面。
原 `AccountPagesFlowTest` 补充作者作品空页响应，继续覆盖关注写入与页面恢复。

## 验收边界

设备测试通过本机 MockWebServer 验证前端请求与交互，不等于云端、真实手机或 Java/MySQL 业务链路已验收。
真实审核/撤回的后端链路仍由任务 13 交付；本轮不改 Java 接口，不接入新的推荐/Agent 能力。
顶部统计来自资料接口，与分页请求之间没有跨接口快照保证；页面刷新会重新获取两者。
