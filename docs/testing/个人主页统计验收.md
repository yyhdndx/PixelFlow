# 个人主页统计接口验收

接口：`GET /api/users/me/stats`。本次补充只改测试与说明，不调整业务接口、数据库结构或部署配置。

## 覆盖范围

`UserStatsApiTest` 的 12 个用例同时供 H2 和 `MySqlUserStatsApiTest` 使用，覆盖：

- 空账号、非负整数、严格四字段响应（不携带密码、令牌或用户明细）、禁止缓存。
- 作品状态过滤、两个作者的数据隔离、伪造查询参数不能切换账号、读取不改变计数。
- 真实创建、提交审核、发布、撤回接口引起的计数变化。
- 真实关注/取消关注接口及重复提交幂等性、关注计数超过 50。
- 停用与恢复启用、停用账号访问被拒绝、关系保留。
- 不存在的关注目标、其他互动类型、关闭个性化和屏蔽作者不影响统计口径。
- 匿名、无效令牌、有效签名但过期的 JWT、过期会话被拒绝。

`UserStatsFailureTest` 单独模拟数据库查询失败，通过真实控制器与统一异常处理验证 HTTP 500、错误脱敏、没有伪造零统计。该测试不验证数据库连接本身，也不替代上述鉴权测试。

## 运行方式

在 `server` 目录执行快速专项测试：

```powershell
mvn '-Dtest=UserStatsApiTest,UserStatsFailureTest' test
```

目标数据库验收使用 Java 17 和独立 MySQL 8.4 实例。先由测试数据库管理员创建专用库（例如 `pixelflow_stats_test`），并向测试账号授权；不要使用云端业务库或联调库。测试会清理库内业务数据，库名必须以 `_test` 结尾。

在测试终端私下设置 `MYSQL_TEST_USER` / `MYSQL_TEST_PASSWORD` 后，设置专用连接地址并运行：

```powershell
# 示例仅用于本机独立测试实例；按实际本地端口调整。
$env:MYSQL_TEST_STATS_URL='jdbc:mysql://127.0.0.1:3306/pixelflow_stats_test?useSSL=false&allowPublicKeyRetrieval=true'
mvn '-Dtest=UserStatsApiTest,UserStatsFailureTest,MySqlUserStatsApiTest' test
```

预期专项共 25 项通过（H2 12、失败注入 1、MySQL 12），无跳过。未设置 `MYSQL_TEST_STATS_URL` 会跳过 MySQL 用例，不算数据库验收通过。

完整回归运行 `mvn test`，报告保存在 `server/target/surefire-reports/`。其他 MySQL 测试各自需要对应环境变量，不能把它们的跳过记录描述为通过。
