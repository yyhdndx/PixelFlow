## 3. 前端最常用的接口入口

详细字段、错误码和分页规则以 [Java OpenAPI](../contracts/http/java-api.yaml)、[Python 契约](../contracts/http/python-analytics.md) 为准，不复制另一套接口规范。

| 页面/动作 | 入口 |
| --- | --- |
| 注册、登录、刷新、退出 | POST `/api/auth/register`、`login`、`refresh`、`logout`（均在 `/api/auth/` 下） |
| 本人资料、编辑、统计 | GET/PUT `/api/users/me`；GET `/api/users/me/stats` |
| 作者主页头部 | GET `/api/users/{id}/profile`，传真实用户 ID |
| 本人粉丝/关注列表 | GET `/api/users/me/followers`、`/api/users/me/following` |
| 点赞、收藏、关注、不感兴趣 | PUT `/api/interactions/{kind}`；kind 分别为 likes、favorites、follows、not-interested |
| 首页与详情 | GET `/feed/`；GET `/api/posts/{id}` |
| 图片上传与管理 | POST/GET `/api/media`；DELETE `/api/media/{id}` |
| 本人作品与草稿 | GET/POST `/api/posts`；PUT `/api/posts/{id}` |
| 提交审核/撤回 | POST `/api/posts/{id}/publish`、`/api/posts/{id}/withdraw` |
| 当前兴趣画像 | GET `/api/users/me/profile`，与 `{id}/profile` 的公开资料不是一回事 |
| 偏好控制 | GET/PUT `/api/recommendations/me/preferences`；PUT `/api/recommendations/me/blocked-authors/{author_id}`、`/api/users/me/profile/topics/{topic}` |
| 历史画像（仅 Python） | GET `/profiles/me/history`；不要让 Android 直接访问 Python |
| 头像设置/清除（待合并部署） | PUT/DELETE `/api/users/me/avatar`；先通过图片上传取得 mediaId |
| 推荐交付（待 Java 实现） | GET `/api/recommendations/me/feed`；单页最多 10 条，由 Java 代理 Python 预览并补全卡片 |

联调注意：

- Android 当前默认 origin 是 `http://10.0.2.2:8080`（模拟器访问本机）；云端联调使用 `http://8.140.36.87`。不在 base URL 后添加 `/feed/`。现有云端是明文 HTTP，仅用测试账号和非真实常用密码；正式安全上线另安排 HTTPS。
- 个人资料、用户主页等受保护接口带用户令牌。服务密钥、数据库凭据、模型密钥不能进入 App；Python 与 MySQL 不开放给手机直连。
- 分页不是同一套字段：Feed/关系列表用 next_cursor、数字 has_more；媒体用 nextCursor/after；Python 历史用 before_version、布尔 has_more。分别映射，别做一个未经验证的“万能分页解析器”。
- 粉丝/关注按用户 ID 排序，Feed 按作品数字 ID 排序，不宣称按关注时间或发布时间排序。
- 开关/屏蔽改变的是推荐偏好，不会让现有普通 Feed 自动按偏好过滤。UI 不要承诺未实现的即时效果。
- 上传支持 JPEG/PNG，8 MiB、400 万像素；“已有视频可播放”不等于“用户可以上传视频”。头像裁剪压缩是客户端后续工作。

## 7. 本轮边界与验收习惯

核心交付是可演示的社区业务闭环，不包含评论、私信、搜索、通知、视频上传、找回密码、完整推荐流或 Agent/MCP。这些后续逐个起 issue，不为“看起来齐全”同时开工。

每个页面验收至少覆盖正常、空列表、断网、未登录/过期登录、账号切换、离开页面后的迟到响应。写请求超时不代表服务端没执行，应通过重新读取确认状态；图片 URL 更新后避免沿用旧头像缓存。服务端 no-store 不等于客户端内存缓存自动失效。

开发测试用各自独立数据库，云端只做受控联调，不跑清表测试。每次联调记录 App 提交、后端提交、设备与服务地址，问题以可复现页面步骤起 issue。
