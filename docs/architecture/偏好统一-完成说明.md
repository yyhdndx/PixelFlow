## 背景与目标

此前推荐偏好存在双写分歧：Java `PUT /api/interactions/not-interested` 保存互动事实，Python `PUT /recommendations/me/exclusions/{post_id}` 另存推荐排除，两者未同步，客户端只写 Java 时 Python 预览不一定过滤。

本任务把推荐偏好的**唯一权威来源收敛到 Java**；Python 偏好接口改为**只读代理 Java** 并停用本地写入，不再保留第三份存储。

## 完成内容

### 1. Java：权威偏好读写

- 新增 `server/src/main/java/com/pixelflow/server/interaction/PreferenceService.java`，负责偏好快照读写、版本递增与主题抑制。
- 偏好快照字段（snake_case）：`user_id、personalized、version、excluded_post_ids、blocked_author_ids、suppressed_topics`。
- 上限：作品排除 ≤ 1000、作者屏蔽 ≤ 500，超限返回 409（`EXCLUSION_LIMIT` 等 code），不静默截断。
- `version` 仅在「实际发生变更」时递增，重复设置不递增。
- 主题白名单（冻结）：美食、宠物、旅行、阅读、数码、运动、园艺。
- 单作品排除复用 `interactions(kind='not-interested')`，不新增存储。
- 身份一律取自经过验证的 `Actor`，不信任请求体中的 user_id。
- 接口变更：

| 方法与路径 | 类型 | 说明 |
|---|---|---|
| `GET /api/recommendations/me/preferences` | 新增 | 返回本人偏好快照，`Cache-Control: no-store` |
| `PUT /api/recommendations/me/preferences` | 新增 | `{personalized:boolean}`，关闭后排除规则仍生效 |
| `PUT /api/recommendations/me/blocked-authors/{author_id}` | 新增 | `{blocked:boolean}`，推荐专用屏蔽 |
| `PUT /api/users/me/profile/topics/{topic}` | 新增 | `{suppressed:boolean}`，topic 需在白名单 |
| `GET /api/users/me/profile` | 增强 | 附加 `suppressed_topics` |
| `PUT /api/interactions/not-interested` | 增强 | 可选 `recommendationId`/`eventId`；同事务更新偏好版本并发 SERVER 事件 |

### 2. Python：只读代理、停用本地写入

- `clients/java.py`：新增 `JavaClient.preferences(token)`，读取并校验 Java 偏好快照形状。
- `api/app.py`：
  - `GET /recommendations/me/preferences` 改为代理 Java（`Cache-Control: no-store`）；会话失效 → 401，上游不可用 → 503。
  - 旧写入入口（PUT preferences / exclusions / blocked-authors）改为返回 410。
  - 推荐预览改为读取 Java 偏好做过滤。
- 删除本地偏好存储 `recommendation/preferences.py`。
- 处理 token 中途撤销竞态：`AuthenticationError` → 401，不再落入 500。

### 3. contracts：契约同步

- `contracts/http/java-api.yaml`：新增 3 个偏好路径，增强 `interactions` 与 `profile` 的 schema。
- `contracts/http/python-analytics.md`：偏好章节替换为「只读代理 Java + 旧写入口 410」的废弃说明。

### 4. 测试

- Java：`mvn test` BUILD SUCCESS；`PreferenceApiTest`（6 个用例）覆盖偏好读写、no-store、主题抑制、not-interested 版本递增与 SERVER 事件、排除上限 409 不截断。
- Python：`pytest` 85 passed，覆盖代理、410、预览过滤、token 撤销竞态。
