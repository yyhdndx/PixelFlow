# PixelFlow 答辩演示脚本（数据闭环版）

> 演示原则：**只展示功能，不展示性能数据**（不提缓存命中率、耗时等）。底层逻辑是一个用户从"浏览 → 行为 → 推荐 → 提问 → 创作 → 发布"的完整旅程，数据从头流到尾、再回到头。

## 一、演示目标

用一个真实用户的完整旅程，展示系统的**数据闭环**：

```
注册登录 → 浏览瀑布流 → 行为画像 → 个性化推荐 → 提问检索 → AI 辅助创作 → 管理员发布 → 回到首页
```

每一步都落在"用户能感知的功能变化"上，不用报任何性能数字。

## 二、演示前准备

| 项 | 内容 |
|---|---|
| 设备 | Android 真机（已装最新 debug 包）+ 一台能看服务器/数据库的电脑 |
| 账号 | 1 个新注册的普通用户（演示主账号）+ 1 个管理员账号 |
| 数据准备 | 提前确认首页有足够的作品可浏览；准备 3~4 篇"美食"主题作品供 Step 2 点赞 |
| 环境确认 | 确认 Python 画像同步任务在运行（Step 2 依赖）；确认推荐首页接入状态（见"关键依赖"） |
| 时间 | 全程控制在 **3~4 分钟** |

### 关键依赖（演示前必须确认）

- **Step 2 的"首页推荐变化"**依赖"首页是否已接入个性化推荐"。
  - 已接入 → 完整演示：点赞后首页出现对应主题作品。
  - 未接入 → 降级演示：只展示"点赞产生行为事件 + 画像得分变化"，**不演示"首页推荐变化"**，台词改为"行为已进入画像"。

## 三、演示脚本（5 步）

### Step 1 · 注册登录 + 访问瀑布流（40s）

**操作**：打开 App → 注册一个新账号（或直接登录）→ 进入首页 → 上下滑动瀑布流浏览几张。

**台词**：
> "这是我们的社区首页，双列瀑布流。用户登录后就能浏览作品，图片有预加载，滑动很流畅，内容连续不断。"

**验证点**：瀑布流正常加载、图片显示、滑动流畅。

---

### Step 2 · 行为 → 画像 → 推荐（50s）

**操作**：在瀑布流里，连续点开 3~4 篇"美食"主题作品，每篇停留几秒，并点赞其中 2~3 篇。返回首页。

**台词**：
> "用户的行为——点击、停留、点赞——会被系统采集，异步聚合成用户画像。等一轮同步后，首页的个性化推荐就会偏向这个用户感兴趣的主题。"

**验证点**：
- 完整版：首页（推荐区）开始出现美食相关作品。
- 降级版：展示画像接口/数据库里"美食"主题得分上升。

**数据佐证（可选，不报具体数字）**：行为事件已写入、画像主题得分变化。

---

### Step 3 · 提问 → 站内检索（40s）

**操作**：点进一个作品详情页 → 打开智能搜索/Copilot → 输入问题（如"帮我找找关于咖啡的作品"或"结合这篇作品帮我写条评论"）。

**台词**：
> "用户提问后，Agent 会在站内检索相关作品，并给出带引用的回答或业务提案——不是凭空编，而是有出处。"

**验证点**：返回结果带作品引用（或草稿/评论提案）。

---

### Step 4 · 创作 + AI 辅助创作 + 管理员发布（60s）

**操作**：
1. 打开创作页 → 用 AI 辅助起草标题/正文（"帮我写一篇咖啡探店分享"）→ 确认填入草稿。
2. 提交审核（状态进入"待审核"）。
3. 切换到管理员账号 → 打开待审核队列 → 展示 AI 给出的审核建议（风险等级 + 建议动作 + 理由）→ 管理员确认通过发布。

**台词**：
> "用户用 AI 辅助写草稿，提交后进入审核。管理员这边会看到 AI 给出的风险建议作为参考，但最终由管理员拍板，确认后发布。"

**验证点**：草稿 → 待审核 → 管理员看到 AI 审核建议 → 发布成功（状态变为已发布）。

---

### Step 5 · 闭环收尾（20s）

**操作**：切回普通用户 → 回到首页 → 指出刚才发布的作品已经出现在首页。

**台词**：
> "刚才发布的作品，现在回到了首页——这就是我们的数据闭环：浏览 → 行为 → 画像/提案 → 内容 → 再回到浏览，每一步都有数据可查。"

**验证点**：新发布的作品在首页可见（可以刷新一下首页让它出现）。

---

## 四、注意事项

1. **别报性能数字**：全程不讲缓存命中率、耗时、占比，只讲"功能有没有跑通、数据有没有流动"。
2. **Step 2 提前演练**：画像同步有延迟，演示前确认同步任务在跑，否则"行为 → 推荐"这一段会卡住。
3. **账号切换要熟练**：Step 4 要切管理员，提前把两个账号都登录好、记住切换路径。
4. **台词简洁**：每步一句核心台词，不要长篇解释；老师追问再展开。
5. **备用方案**：如果某个环节现场失败（如推荐没变化、Agent 超时），直接跳过该步进入下一步，不要当场调试。
