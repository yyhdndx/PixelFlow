# [Java] 本人历史画像代理

状态：2026-10-21 已实现并完成本地验证，线上发布结果需单独确认。验证结果见 [验收记录](../testing/后端接口补全验收.md)。

Android 后续历史画像页面通过 Java 网关读取已有 Python 快照，无须开放内部分析端口。

## 接口

`GET /api/users/me/profile/history?count=20&before_version=8`，需要用户 Bearer token。count 默认20、范围1–50，before_version 首页省略，范围1–9223372036854775807。仅接受 ASCII 十进制正整数，允许前导零；显式空值、非数字、越界和重复分页参数返回400 `INVALID_ARGUMENT`。不接受通过 userId/user_id 切换身份，仅转发校验后的分页参数及当前用户令牌。

响应沿用 Python 历史接口：user_id、items、布尔 has_more、字符串或 null 的 next_cursor。版本数字降序，末页游标为空；无历史返回空 items，不合成冷启动快照。

Java 检查上游本人归属、摘要字段、有限数值、降序版本和游标一致性，白名单输出摘要。历史不按当前推荐偏好重写；不触发分析、重算、数据库写入或偏好更新。

全部响应禁止缓存。未登录、失效会话或停用账号沿用401；上游401映射401；无效JSON/摘要或身份不符返回502；未配置、超时、连接失败或其他上游非成功状态返回503。禁止回显上游正文或令牌，不跟随重定向。

## 验证范围

独立本地 HTTP 上游验证真实 Java HTTP 客户端的令牌及参数转发、首末页、最大long、跨账号拒绝、当前偏好隔离、白名单、无效摘要、重复参数、超时和错误映射。鉴权通过真实注册/登录会话验证；未认证请求不能访问上游。

仅新增 Java 控制器、分页参数解析和测试，复用现有服务地址配置，不增加依赖或数据库迁移。Python 原生接口的422参数错误保持不变；Android页面、周期调度、推荐代理、Agent和服务器发布不在本任务中。
