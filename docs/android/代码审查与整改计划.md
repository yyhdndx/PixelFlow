## 分批实施

第一批处理 A01–A06 的明确逻辑错误，补充相应回归测试。A07–A11 涉及存储 API、页面状态、媒体生命周期和授权流程，应逐项改造与设备验证，避免同时改写所有 Activity。第二批完成持久化异步化及媒体选择、播放器和转场治理；第三批处理示例数据、性能与测试覆盖。

## 回归场景

1. 相同实体类配不同 DataType 时必须得到隔离仓库；关注写入 follow_status，点赞写入 like_status。
2. 清理内存缓存后，后台重新读取仍能获取磁盘记录。
3. 非法 URL、HTTP 500、空响应、非 JSON、取消请求均不崩溃，不重复调用业务回调。
4. 加载更多途中刷新、快速切换首页和个人页、销毁后重建视图，旧响应不得更新新列表。
5. 相邻页重复 ID 只出现一次；刷新为空清空列表，刷新失败保留已有列表。
6. 多次刷新后线程数不持续增加；恢复零赞正确；恢复任务不覆盖最新点赞操作。
7. 点击尚未接入服务的发布按钮，不显示成功、不关闭编辑页、不返回成功结果。
